# Animais Sem Teto

## Sobre o projeto

O Animais Sem Teto é uma aplicação web desenvolvida como projeto acadêmico. A aplicação apresenta uma interface para uma ONG voltada ao resgate, cuidado e adoção responsável de animais.

O projeto foi desenvolvido no formato de uma Single Page Application (SPA), permitindo navegar entre Início, Projetos e Cadastro sem carregar novas páginas HTML.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- Template Literals
- localStorage
- Git e GitHub

## Funcionalidades

- Navegação entre as áreas da aplicação sem recarregar a página
- Menu responsivo com botão hambúrguer
- Exibição dinâmica dos projetos
- Formulário de cadastro
- Máscaras para CPF, telefone e CEP
- Validação dos campos do formulário
- Feedback visual para campos válidos e inválidos
- Mensagem de confirmação após o cadastro
- Armazenamento dos dados do cadastro no localStorage
